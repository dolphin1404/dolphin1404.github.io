외부 서비스와 데이터 전달

  • Supabase: 계정·단어장·메모·이용량·구독·신고 등 서비스 데이터와 서버 기능을 관리합니다. NAMU_APP 프로젝트의 DB 리전은 일본 도쿄(ap-northeast-1)로 구성되어 있습니다.
  • OpenAI API: AI 학습 기능을 요청하면 해당 기능의 입력을 서버를 통해 OpenAI API로 전달합니다. 입력에는 기능에 따라 학습 단어, 기존·거절 단어, 관심사·언어·수준 또는 첨삭을 요청한 에세이가 포함됩니다. 부정 사용 방지를 위해 서비스 계정 ID에서 계산한 가명 안전 식별자도 함께 전달합니다.
  • 음성 합성 연동: 팟캐스트 대본의 SSML 텍스트와 선택한 음성·언어·속도 설정을 음성 생성 서버에 전달합니다.
  • Google AdMob·UMP: 광고 제공과 광고 관련 동의 상태 확인에 사용합니다.
  • Google Play: 결제와 구독 관리 및 구매 검증에 사용합니다. 구매 연결을 위해 서비스 계정 ID에서 계산한 식별자가 사용됩니다.
  • 로그인 제공자: 선택한 외부 로그인 방식의 인증 결과를 계정 로그인에 사용합니다.

서비스 제공을 위해 필요한 정보는 해당 기능 이용 시 네트워크로 전달됩니다. Supabase DB 리전은 AI·광고·결제 업체의 모든 처리 장소를 뜻하지 않습니다. 외부 처리에는 각 업체의 서비스 정책과 설정이 적용됩니다.

OpenAI의 공식 API 정책에 따르면 입력과 응답은 명시적으로 데이터 공유를 선택한 경우를 제외하고 모델 학습이나 개선에 사용되지 않습니다. 부정 사용 방지용 로그에는 입력·응답과 관련 정보가 포함될 수 있으며, 기본적으로 최대 30일 보관됩니다. 법적 의무 또는 서비스와 다른 사람의 안전 보호를 위해 더 오래 보관될 수 있습니다.

NAMU는 생성 응답을 나중에 API로 다시 조회하는 저장 옵션을 끄고 요청합니다. 이 설정이 안전 점검용 로그나 요청 처리 캐시까지 모두 없애는 것은 아니며 무보관을 보장하지 않습니다. AI 요청에는 다른 사람의 개인정보, 민감정보나 비밀정보를 입력하지 마세요.

신고와 지원 메일

AI 콘텐츠 신고는 앱 안에서 사유를 직접 작성하고 전송에 동의한 경우 보냅니다. 생성된 원문, 에세이 전체, 팟캐스트 대본이나 오디오를 자동 첨부하지 않습니다. 사용자가 신고 사유에 직접 입력한 내용은 전송됩니다.

서버 저장이 확인된 경우에만 접수 완료로 표시합니다. 운영자가 신고 사유와 참조 정보를 확인하고 필요한 대응을 진행합니다. 접수 표시는 문제의 검토·해결 완료를 뜻하지 않습니다.

지원 피드백은 외부 이메일 앱에서 초안을 엽니다. 로그인 중이면 계정 ID가 포함되며, 회신 주소 입력이 비어 있으면 계정 이메일을 사용합니다. 이메일 앱에서 내용을 확인·수정하고 보내기 버튼을 눌러야 전송됩니다.

광고와 개인정보 선택

무료 이용 기능에는 광고가 포함될 수 있습니다. 앱은 광고 요청 전에 Google UMP의 동의 정보를 확인하고 필요한 경우 동의 양식을 표시하도록 구성되어 있습니다. 광고 SDK에서 요청 가능 상태가 확인되지 않으면 광고를 요청하지 않습니다.

광고 관련 선택에는 해당 동의 화면과 기기·Google 광고 설정도 적용됩니다. Google 광고 정보와 관리 방법을 확인할 수 있습니다. 회원 탈퇴와 광고 서비스의 별도 정보 관리는 각각의 절차입니다.

보관기간과 삭제

  • 회원·학습 정보: 계정을 사용하는 동안 보관하며, 회원 탈퇴 처리 시 해당 계정의 회원·단어장·단어·메모 등 연결 데이터를 삭제합니다.
  • 서비스의 구매·구독 연결 기록: 계정과 연결된 서비스 데이터로 관리하며 계정 삭제 대상에 포함됩니다. Google Play가 별도로 관리하는 결제·거래 기록에는 Google의 정책이 적용됩니다.
  • 지원 문의·AI 신고·삭제 요청 기록: 운영자가 요청을 처리하는 동안 보관하고, 처리 완료 후 운영자가 관리하는 기록을 삭제합니다. AI 신고 기록은 해당 계정의 탈퇴 시에도 삭제 대상에 포함됩니다.
  • 서비스 로그와 외부 업체 보관분: 보안·부정 사용 방지·서비스 운영을 위한 로그와 제공업체의 보관은 각 서비스 정책·요금제·설정에 따릅니다. 회원 탈퇴만으로 외부 업체의 모든 로그·백업·결제 기록까지 즉시 삭제되지는 않습니다.

개인정보의 확인·정정·삭제 및 처리 관련 문의는 위 이메일로 보낼 수 있습니다. 계정 삭제 안내에서 앱 내부 경로와 앱을 다시 설치하지 않고 문의하는 방법을 확인할 수 있습니다.

앱의 계정 삭제는 서버에서 계정과 연결 데이터의 삭제가 확인된 경우에만 완료로 표시합니다. 서버를 사용할 수 없거나 삭제를 확인하지 못하면 완료로 표시하지 않습니다.

서버 삭제가 확인되면 현재 설치본의 로컬 팟캐스트와 환경설정 캐시 정리를 시도합니다. 다른 기기의 다운로드, 이미 내보낸 파일과 외부 서비스가 별도로 보관하는 정보는 이 요청만으로 모두 삭제되지 않습니다. 계정 삭제는 Google Play 구독 취소와 별개입니다.
